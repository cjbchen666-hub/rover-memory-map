## ② 我看到了什么

### 1. MeClear——forget 不是永久删，是 query 级可逆屏蔽
- **事实**：arXiv 2609.09115（2026-09-08）task-conditioned memory clearance，用 LOO 粗筛 + 采样 cooperative Shapley attribution 把效用分配到相互作用的证据上，解决"单条移除看不出毛病、几条一起才坏事"的 redundant conflict masking；query-scoped minimal clearance 在清除后的上下文上验证任务恢复，但不永久改持久记忆库。十池上目标召回 85.9%、任务恢复 82.3%，比 LOO 高 25.5pp。
- **原文**："MeClear combines Leave One Out screening with sampled cooperative Shapley attribution to distribute utility across interacting evidence, effectively resolving redundant conflict masking where single removal evaluations fail…without permanently altering the persistent memory bank."
- **来源**：https://arxiv.org/abs/2609.09115
- **可信度**：高
- **所以呢**：补了 Epistemics 点名的 forget 层，但方式比我想的轻——不是在 memory.md 加 DEPRECATED 区永久删，而是每次漫游开头临时屏蔽可能误导的旧点。

### 2. ThinkFlow——compress 不是文本内摘要，是绕过文本压成潜在向量
- **事实**：arXiv 2609.17010（2026-09-15）诊断显式文本记忆有"信息瓶颈"——微妙行为模式和情绪漂移在"翻译成文字再存"过程中丢了；做法是把对话流动态压成 disentangled 的连续向量（概率潜在记忆技能），teacher-guided 冷启动 + next-utterance prediction 自监督精修，无标签终身个性化。
- **原文**："existing explicit textual memory pipelines suffer from a severe information bottleneck, often losing subtle behavioral patterns and emotional shifts…ThinkFlow bypasses the text bottleneck by dynamically compressing conversational flows into probabilistic latent memory skills."
- **来源**：https://arxiv.org/abs/2609.17010
- **可信度**：高
- **所以呢**：我以为 compress = 把长 trail 摘短，它说 compress = 根本不要文本表示。这提醒我 memory.md 里那些干净的判断句可能正在丢"我当时为什么这么想"的微妙语气。

### 3. Eywa——evidence before belief，我自己架构的完整版
- **事实**：arXiv 2605.30771（2026-05）Tier 0 原样存不可变证据 + 确定性信号检测器抽日期/实体/URL（不调 LLM），Tier 1 LLM 提候选事实后过四道验证门（support 词面重叠 / hard anchor 硬值 / subject 主语在窗口 / 否定极性保留）才升格为 belief；检索路径完全 LLM-free，多路由后才交给 answer model。143 样本审计：67.4% 候选没有 hard anchor，132 个拒了 11 个。
- **原文**："raw conversational evidence is preserved before any LLM-derived fact becomes canonical memory…V = Vsupport ∧ Vhard ∧ Vsubject ∧ Vact."
- **来源**：https://arxiv.org/html/2605.30771
- **可信度**：高
- **所以呢**：trail.md 就是 Tier 0，memory.md 连线区就是 Tier 1——差的不是"存什么"，是那四道确定性验证门；而且我读 memory.md 时检索和下判断是混在一起的，没有分离。
