## ② 我看到了什么

**[1. Pages 真实发布源是 rover/web/ 产物，不是仓库根目录]**
事实：deploy.yml 末尾 upload-pages-artifact 明确 `path: rover/web/`，随后 actions/deploy-pages@v4 把整个 rover/web/ 目录作为 Pages 站点发布；也就是说浏览器访问的 index.html 来自这次 CI 重新 fetch 数据后构建出的 web 子目录产物。
原文摘录：`uses: actions/upload-pages-artifact@v3` / `with:` / `  path: rover/web/`。
来源：本地 web/deploy.yml（线上同路径 .github/workflows/deploy.yml）；线上 Pages https://cjbchen666-hub.github.io/rover-memory-map/ ｜可信度：高。
所以呢：Pages 走的是 artifact 通道，根目录那份 index.html 在这条链路里根本不在发布包内，是典型的"发布源与仓库文件脱节"。

**[2. CI 又把 rover/web/index.html 复制到根目录并 git push，制造第二份副本]**
事实：构建后单独一步 `cp rover/web/index.html index.html`，git add、有 diff 就 `git commit -m "build(index.html): auto rebuild from Rover data"` 并 `git push origin main`；这一步自称 branch-based Pages fallback，但当前 Pages 已走 artifact，fallback 已无对象。
原文摘录：`cp rover/web/index.html index.html`；`git commit -m "build(index.html): auto rebuild from Rover data [skip ci]"`。
来源：本地 web/deploy.yml（线上 .github/workflows/deploy.yml）｜可信度：高。
所以呢：根目录 index.html 是每次构建后多写一份的死副本，既不被 Pages 读取，又在 main 分支历史里堆 commit，纯属冗余回写。

**[3. [skip ci] 只防自触发循环，不消除每次一次的 main 分支 push]**
事实：commit message 带 `[skip ci]`，目的是让这次 push 不再二次触发 workflow；但它仍真的 push 到 origin/main，只要 index.html 有字节变化就产生一条 build(index.html) commit，与 deploy.yml 的快照 push 并列写历史。
原文摘录：`build(index.html): auto rebuild from Rover data [skip ci]`；`git push origin main`。
来源：本地 web/deploy.yml；仓库 main 历史可见连续 build(index.html) commit ｜可信度：高。
所以呢：跳过 CI 不等于不写仓库——历史里每天有 deploy 快照 push 加一批 build(index.html) push，两类 commit 混在一条线上，回溯时难以一眼区分"改了数据"还是"只是重建了页面"。

**[4. 根目录副本与 artifact 同源但不同寿命，一旦 Pages 切回 branch 模式会立刻错位]**
事实：根目录 index.html 是上一次 CI 落盘的快照，而 artifact 每次都在同一个 job 里重新 fetch STATE/MEM/TRAIL/RPT 再构建；若将来 Pages 配置从 GitHub Actions artifact 切回分支根目录模式，发布的将是这个可能滞后、且只存 index.html（不含 data.json/vendor）的根目录文件，与 rover/web/ 完整产物不一致。
原文摘录：`cp rover/web/index.html index.html`（只拷单文件，不拷 data.json/vendor/）；artifact `path: rover/web/`（整目录）。
来源：本地 web/deploy.yml ｜可信度：中高。
所以呢：这个"fallback"拷贝是不完整的——只搬 HTML 不搬它依赖的 data.json 和 vendor/echarts.min.js，真当 fallback 用也跑不起来，是半成品保险。
