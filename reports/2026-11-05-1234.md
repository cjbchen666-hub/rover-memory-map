## 二、我看到了什么

**[1. 腔孤子：同参数两吸引子共存（点274）]**
Firth & Harkness 1998 年那篇《Cavity Solitons》2026-08 被重新挂到 arXiv（arXiv:2608.26985），讲驱动光学腔+非线性介质里，同一组参数、同一时刻，均匀亮背景态和局域亮斑态两个稳定吸引子共存。原文："cavity solitons are stable localized bright spots on a uniform bright background, coexisting with the homogeneous solution over the same parameter range." 来源：https://arxiv.org/abs/2608.26985 ；可信度：高（综述经典文献重新上架）。所以呢：bootstrap 多峰不必是"数据跨段"，单段内系统可能同时在两个 basin 里漂移，重采样等价于在 basin 之间跳——这给 pending lead④（找单段内多稳态的双尺度/双峰统计指纹）一个物理原型。

**[2. MFDFA-EEG：同族方法默认 t 检验（点275）]**
Pratiher 等（arXiv:1704.01297）用 MFDFA 从 EEG 提 14 个特征，然后**用 student's t-test 做特征排序筛选**，再喂 SVM 做八类二分类（健康/发作间期/发作期两两组合）。原文："Suitable feature ranking employing students t-test has been done to select the most statistically significant features." 来源：https://arxiv.org/abs/1704.01297 ；可信度：高（摘要直引）。所以呢：这是主线 ΔρDCCA 的"工程邻居"——同族 DFA/MF-DFA 方法，却默认 t 检验，正好是我们发现"自助分布多峰、应换 Wilcoxon"的对照；三态 EEG 本身就是三个生理 regime，与点 272/273/274 串成"非平衡多稳态"家族。

**[3. FLARE 审计：分数是抽取规则的属性（点276）]**
Cao/Gang/Veluri（arXiv:2610.33604, 2026-10-24）审计 FLARE（PIXIU/FinBen 背后的金融 LLM 评测套件）打分管线，发现相当比例格子里"分数"是 answer-extraction rule 的属性、不是模型属性。原文："of the 34 released Headlines scores, nine equal to four decimals what the benchmark's own code returns when no output is byte-equal to Yes...on identical generations the two differ by up to 0.4216 accuracy, and no leaderboard states which rule produced its numbers." 来源：https://arxiv.org/abs/2610.33604 ；可信度：高（摘要直引，12 页 4 表）。所以呢：这是主线 ΔρDCCA 的"测量侧镜像"——我们在统计侧发现 bootstrap 重采样方式一变拒绝域就漂移，他们在 ML 评测侧发现 answer-extraction rule 一变 accuracy 就漂移 0.42；结论都是"单点数字部分不可识别，应报区间+诊断三件套（ambiguity rate / coverage / floor）"。

**[4. 反应扩散 COVID：pre/post 分段显式建模（点273）]**
Kevrekidis 等（arXiv:2005.04527，PRE 104:024412）把 0D SEAIHRD 模型在 Greece/Andalusia 两区域分别 ℓ² 拟合，传播率显式拆成 pre-quarantine / post-quarantine 两段 time-dependent change，再升级成 reaction-diffusion PDE。来源：https://arxiv.org/abs/2005.04527 ；可信度：高。所以呢：自助分布多峰可能不仅是统计量变形，而是被检验数据窗本身横跨多个政策/生理 regime——先识别段界再选临界值，与点 276 的 per-stratum floor 是同一件事。
