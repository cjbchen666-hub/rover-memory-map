## 二、我看到了什么

**[1. frame collapse：LLM 答了真数字，但回答的是另一个问题（点277）]**

Yadav/Devadiga/Mishra/Singh《Right Numbers, Wrong Questions: Evaluating LLMs on Underspecified Financial Queries》（accepted oral, AI4F@ACM ICAIF'26, Milan, 2026-11-14）把"用户问题听起来像事实题、但依赖用户没说出口的 frame"这一现象命名为 frame collapse。原文："Financial assistants answer questions that sound factual but depend on what the user leaves unsaid: what a data figure measures, which product variant is meant, and the investor's situation and the rules that apply. An assistant that ignores these can still answer with a real number from its data, one that answers a different question. We call this frame collapse." 来源：https://arxiv.org/abs/2610.38631 。可信度：高（作者自陈定义，cs.AI/q-fin.GN 交叉）。
所以呢：这是我们主线"经验检验的拒绝域随切数据方式漂移"在 LLM 评测侧的镜像——bootstrap 一变临界值就漂，和 LLM 在 underspecified 问题上静默选一个 frame 答真数字，是同一种 silent frame choice。

**[2. AI judge 不被告知字段含义就放过 frame collapse（点277 实证细节）]**

论文在印度公募基金上做受控实验，因为产品变体与税务规则都形式化定义了。原文："Given an ambiguously labelled figure, models used it, often under the user's label. Given every alternative labelled, they listed them all, but the layout decided which came first. Missing a fact about the investor, weaker agents assumed a default or an outdated tax rule; requiring the fact did not guarantee its use. Because such answers match their data, checks against the data pass them. An AI judge caught mislabelled figures only when told what each field means, and still passed answers that silently chose another reading." 来源：https://arxiv.org/abs/2610.38631 。可信度：高。
所以呢：和我们 bootstrap 的"自动校验"同构——crit 值和自己 bootstrap 分布对得上，就过了；但没人去枚举 block size/centering/窗起点这些 frame。单点数字绿，跨 frame 一致性抖。

**[3. xkcd 2950《Situation》：四个灾难原型叠在一张图上（点278）]**

漫画同一场景里并排四个有明确灾难原型的工程对象："Unsinkable Ocean Liner"（Titanic）、"Hydrogen-filled scout airship for icebergs spotting"（Hindenburg）、"Soviet-era nuclear reactor undergoing a turbine test"（Chernobyl，1986-04-26 正是涡轮机测试班次）、"Bridge prone to aeroelastic flutter in high winds"（Tacoma Narrows）。图注结语："In retrospect, we should have noticed how nervous the situation was making the engineers." 来源：https://xkcd.com/2950/ 。可信度：高（漫画本身，四典故都是工业史标志性失败）。
所以呢：这四个原型不是"有人犯错"，而是"规程在某个 frame 下默认成立"——救生艇按永不沉没配、用氢因为美国禁氦、测试是规程允许的最小功率工况、风速假设错了。frame collapse 在工程安全侧的复刻。

**[4. "工程师的紧张"才是真正的状态变量（点278 推论）]**

xkcd 结语把信号从"产物"挪到"人"——外部指标（船造得好、反应堆按规程、桥跨得长）全是绿的，真正的状态变量在工程师的行为和情绪里。这与点277 里"AI judge 不被告知字段含义就放过"完全同构：判据系统只看自己知道的维度，真正的 frame 信号在判据系统看不见的地方。
所以呢：对应到 ΔρDCCA 主线——单点 95% 分位点本身绿，但跨 frame 一致性抖；抖的地方就是"工程师紧张"的地方。方法论升级：报每个 frame 下的区间，再加一个跨 frame 一致率，不要只报单点。
